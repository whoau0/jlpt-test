# 🇯🇵 JLPT N5 한자 마스터 103 (JLPT Kanji 103)

> **JLPT N5 필수 한자 103자 완벽 암기 반응형 모바일 웹 애플리케이션**  
> 훈독(뜻으로 읽기), 음독(소리로 읽기), 실전 어휘까지 **일본어 AI 음성**과 함께 인터랙티브하게 학습하세요!

---

## ✨ 주요 기능

### 1. 🗂️ 스마트 3D 플래시카드 (Flashcards)
- 카드 앞면(한자, 획수, 부수)을 터치하면 부드러운 3D 애니메이션으로 뒤집힙니다.
- 카드 뒷면에서 **훈독(訓読み)**, **음독(音読み)**, **어원 및 연상 기억 비결(Tip)**, **실전 활용 어휘**를 한눈에 확인.
- 훈독/음독 및 어휘마다 개별 **🔊 음성 재생 버튼**을 지원하여 원어민 발음을 즉시 청취 가능.
- `[외웠어요!]` 및 `[다시 볼래요]` 버튼으로 암기 상태 자동 분류.

### 2. ✍️ 주관식 빈칸 채우기 퀴즈 (Fill-in-the-Blank)
- 의미(뜻) 또는 훈독(히라가나)을 빈칸으로 가려 직접 적어보는 주관식 모드.
- 모바일 친화적인 **빠른 히라가나 힌트 칩** 제공.
- 오답 시 즉각적인 해설과 함께 오답노트에 자동 등록.

### 3. 🎯 다채로운 4지선다 객관식 퀴즈 (Multiple Choice)
- 4가지 유형이 무작위로 출제:
  1. **한자 ➔ 한국어 뜻/음 맞히기**
  2. **한자 ➔ 일본어 훈독(訓読み) 맞히기**
  3. **한자 ➔ 일본어 음독(音読み) 맞히기**
  4. **뜻/발음 ➔ 한자 찾기 (역방향 퀴즈)**

### 4. 🔁 오답노트 & 무한 반복 클리닉 (Weakness Repeat)
- 틀린 한자들만 자동으로 모아 오답 횟수를 실시간 집계.
- **`[오답만 모아서 반복 풀기]`** 모드를 통해 100점을 맞을 때까지 집중 훈련.
- 정답을 맞히면 오답 카운트가 차감되어 마스터 시 자동 졸업.

### 5. 📚 N5 103자 전체 한자 사전 & 검색 (Dictionary)
- 103자 전체 그리드 뷰 및 카테고리별 필터(숫자, 시간, 방향, 사람, 신체, 자연, 동사, 형용사, 사회/장소).
- 실시간 검색 기능(한자, 뜻, 음, 발음).
- 클릭 시 상세 모달(부수, 획수, 예문, 음성) 팝업 제공.

### 6. 🌐 N4 ~ N1 상위 등급 로드맵
- N4(181자), N3(370자 / '再' 수록), N2, N1 등급 안내 및 로드맵 수록.

## 🛠️ 기술 스택
- **Frontend:** Pure HTML5, Modern CSS3 (Flexbox/Grid, 3D Flip Transform), Vanilla JavaScript (ES6+)
- **Audio:** 
  - **Web Speech API (`ja-JP`):** 일본어 AI 음성 합성(TTS)
  - **Web Audio API:** 자체 신디사이저 효과음 (정답 딩동댕, 오답, 카드 뒤집기 사운드)
- **Storage:** `localStorage` 기반 학습 진도 및 오답노트 영구 저장
- **Design:** Mobile-First Responsive Web App (PWA 최적화)
